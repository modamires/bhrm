# بازی بهرام — آمادهٔ انتشار در GitHub Pages

این بسته همان بازی نسخهٔ ۱.۳ است، با چیدمان مناسب انتشار از ریشهٔ مخزن. به نصب Node.js یا Python برای اجرای آنلاین نیاز ندارد.

## انتشار از طریق مرورگر

۱. فایل ZIP را کامل از حالت فشرده خارج کنید.
۲. در GitHub یک مخزن عمومی (Public) مثلاً با نام `bahram-game` بسازید. برای آسان‌تر شدن بارگذاری، گزینهٔ ساخت README را فعال کنید.
۳. در صفحهٔ مخزن، `Add file → Upload files` را انتخاب کنید.
۴. همهٔ فایل‌ها و پوشه‌های داخل بستهٔ استخراج‌شده را به صفحهٔ بارگذاری بکشید. خود ZIP را بارگذاری نکنید. فایل `index.html` باید در ریشهٔ مخزن، کنار `question-bank.html` و پوشه‌های `assets`، `src` و `styles` باشد؛ پوشهٔ اضافی دور آن‌ها ایجاد نکنید.
۵. تغییرات را روی شاخهٔ `main` ثبت کنید (Commit changes). اگر تغییرات را در شاخهٔ جداگانه ثبت کردید، ابتدا آن‌ها را در `main` ادغام کنید.
۶. به `Settings → Pages` بروید و این مقادیر را انتخاب کنید:

| گزینه | مقدار |
| --- | --- |
| Source | Deploy from a branch |
| Branch | main |
| Folder | /(root) |

۷. `Save` را بزنید. پس از پایان انتشار، لینک بازی در همین صفحه نمایش داده می‌شود. وضعیت انتشار را از تب Actions نیز می‌توانید ببینید.

اگر نام شاخهٔ اصلی چیز دیگری است، همان را به جای main انتخاب کنید. این بسته برای روش Deploy from a branch آماده شده و workflow جداگانه لازم ندارد.

## نشانی‌ها

اگر نام کاربری `USERNAME` و نام مخزن `bahram-game` باشد:

- بازی: `https://USERNAME.github.io/bahram-game/`
- بانک سؤال: `https://USERNAME.github.io/bahram-game/question-bank.html`

این نشانی‌ها الگو هستند؛ لینک واقعی را از Settings → Pages کپی کنید.

## تغییر بانک سؤال برای همهٔ بازیکنان

۱. بانک سؤال معلم را از منوی بازی باز کنید.
۲. سؤال‌ها را همراه تصاویر اضافه یا ویرایش و ذخیره کنید.
۳. دکمهٔ «خروجی بانک با تصاویر» را بزنید.
۴. فایل دانلودشدهٔ `question-bank.json` را در ریشهٔ همین مخزن، کنار `index.html`، جایگزین فایل هم‌نام و تغییرات را ثبت کنید.
۵. پس از پایان انتشار، بازیکنانی که بانک محلی ندارند، بانک جدید را دریافت می‌کنند. در مرورگری که قبلاً بانک محلی ساخته یا وارد کرده‌اید، دکمهٔ «بارگذاری نسخهٔ منتشرشده» را بزنید.

ذخیره‌کردن سؤال در پنل به‌تنهایی مخزن GitHub را تغییر نمی‌دهد. پنل حساب کاربری یا اتصال نوشتن به GitHub ندارد؛ فایل خروجی را خودتان در مخزن بارگذاری می‌کنید. سؤال‌های فعلی بازی نمونه‌اند.

## اگر صفحهٔ بازی باز نشد

- محل فایل index.html باید ریشهٔ مخزن باشد.
- تنظیمات Pages باید main و /(root) باشند.
- فایل‌ها را از ZIP خارج و همراه ساختار پوشه‌ها بارگذاری کنید.
- در صورت خطای انتشار، تب Actions را بررسی کنید.
- فایل‌های منتشرشده را با لینک HTTPS بازی باز کنید.
