# بازی بهرام | نسخهٔ ۱.۵ برای GitHub Pages

این بسته بدون نصب نرم‌افزار اضافی از ریشهٔ مخزن GitHub Pages اجرا می‌شود. پنل معلم و بانک سؤال مرورگر حذف شده‌اند. پانزده سؤال فایل ارسالی، برای پایه‌های هفتم، هشتم و نهم، مستقیم در بازی قرار دارند: دو سؤال در مرحلهٔ اول، دو سؤال در مرحلهٔ دوم و یک سؤال در مرحلهٔ سوم هر پایه. تصویر سؤال اول هفتم همراه بازی است.

سؤال چهارم نهم در فایل گزینه نداشت؛ در بازی پاسخ آن با چیدن «مُجاهِد» و سپس «مُجاهِدَة» ساخته می‌شود. فهرست سؤال‌ها و پاسخ‌های ثبت‌شده را در `QUESTIONS.md` ببینید.

## به‌روزرسانی انتشار قبلی

فایل‌های داخل ZIP را با حفظ ساختار پوشه‌ها در ریشهٔ مخزن جایگزین کنید. `index.html` باید کنار پوشه‌های `assets`، `src` و `styles` بماند. اگر نسخهٔ قبلی منتشر شده، فایل‌های قدیمی `question-bank.html`، `question-bank.json`، `styles/bank.css`، `src/editor/editor.js`، `src/data/BankStore.js` و `src/data/factories.js` را از مخزن حذف کنید. بارگذاری ZIP به‌تنهایی فایل‌های قدیمی مخزن را پاک نمی‌کند.

GitHub Pages را در `Settings → Pages` روی `Deploy from a branch`، شاخهٔ `main` و پوشهٔ `/(root)` تنظیم کنید. پس از انتشار، صفحه را با `Ctrl+Shift+R` تازه کنید. تنظیمات نمایش و پیشرفت قبلی مرورگر حفظ می‌شوند؛ سؤال‌های بانک قدیمی دیگر خوانده نمی‌شوند.

نشانی نمونهٔ بازی: `https://USERNAME.github.io/bahram-game/`. خود ZIP را روی Pages آپلود نکنید؛ فایل‌های داخل آن را بارگذاری کنید.

## نمایشگر وال

در منوی بازی «حالت وال» را روشن کنید و دکمهٔ تمام‌صفحه را بزنید. در مرورگرهایی که درخواست تمام‌صفحه را نمی‌پذیرند، `F11` را بزنید. نشانی با `?wall=1` حالت وال را مستقیم فعال می‌کند؛ `?wall=0` آن را خاموش می‌کند.

کادر سؤال و دوربین تا خروج از محدودهٔ سؤال ثابت می‌مانند. «نمایش کامل» برای خواندن سؤال‌های بلند و تصویر، بازی را موقتاً متوقف می‌کند. صفحهٔ بازی با نسبت ۱۶:۹، حاشیهٔ امن و خروجی Canvas تا 4K نمایش داده می‌شود؛ روی نمایشگر فوق‌عریض، کناره‌ها خالی می‌مانند تا تصویر بریده نشود. تقسیم تصویر بین پنل‌های فیزیکی و فاصلهٔ قاب‌ها به تنظیمات کنترلر وال بستگی دارد.
